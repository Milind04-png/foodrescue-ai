# Contributing to FoodRescue AI

Thank you for your interest in contributing to **FoodRescue AI**! We welcome community contributions, bug fixes, algorithm enhancements, and NGO partnerships.

---

## 🛠️ Development Workflow

1. **Fork & Clone**:
   ```bash
   git clone https://github.com/Milind04-png/foodrescue-ai.git
   cd foodrescue-ai
   ```

2. **Install Dependencies**:
   ```bash
   # Frontend
   npm install

   # Backend
   pip install -r requirements.txt
   ```

3. **Start Local Development**:
   ```bash
   npm run dev
   ```

4. **Code Quality**:
   - Maintain clean, modern modular architecture.
   - Run `npm run build` before pushing to verify bundle compilation.
   - Ensure zero TypeScript/lint issues in UI components.

---

## 📜 Pull Request Guidelines

- Branch naming: `feat/feature-name` or `fix/issue-description`.
- Keep commits clear, semantic, and well-described.
- Update documentation and mock data tests where applicable.
